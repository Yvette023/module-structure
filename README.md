# 模块结构 · 排版变体库

把「结构1 / 2 / 3 / 4 / 5」五类模块拆成可切换的排版变体：**不换品牌、不换内容，只换排版结构**。
打开 `index.html` 即可，每个结构下方有一条控制条，点一下就切换变体（含数量、方向、对齐、列表样式、镜像、构图、轮播等）。

> 纯静态页面，无构建、无依赖；直接双击 `index.html` 就能看（图片走 Unsplash CDN，需联网）。
> `editor.html` 是同一套模块的**装修编辑页**：画布改什么，右侧面板就有什么开关。

每个结构都是「一个 HTML 片段 + 一份独立 CSS」，可以单独拿出来用。

## 二、结构 01 · 中心图 + 左右双排列表

中间一张主视觉，左右各一列列表。参考图：`结构1-双排列表/`。

| 变体 | 类名 | 说明 |
| --- | --- | --- |
| A 双列均布 | `.m1--a` | 图标在上、文案居中，沿竖向等距铺满图片高度（最稳） |
| B 错位偏移 | `.m1--b` | 两列整体上下错开，靠图一侧文字向图对齐，图片拉高（杂志感） |
| C 紧凑内联 | `.m1--c` | 图标移到标题左侧小方底板，密度最高，适合 8 条 |
| D 编号序号 | `.m1--d` | 去掉图标，用大号数字 01–0N 做视觉锤 |

可变量：

- **列表数量**：4（2+2）/ 6（3+3）/ 8（4+4）
- **排布方向**：`竖向`（左右各自成列，上下顺读：左 1–3、右 4–6）
  / `横向`（列表项横向并排，同时改成左右交替阅读：左 1/3/5、右 2/4/6）
- 横向 + 每侧 3 项时会自动收起描述（`.is-h-dense`），保持一行干净

```html
<div class="m1 m1--b count-4 is-v">
  <div class="m1__grid">
    <div class="m1__col m1__col--left"><ul class="m1__list">…</ul></div>
    <figure class="m1__media"><img src="…" alt=""></figure>
    <div class="m1__col m1__col--right"><ul class="m1__list">…</ul></div>
  </div>
</div>
```

## 三、结构 02 · 一侧文案 + 列表，另一侧整图

参考图：`结构2-单列表/`。

| 控制项 | 取值 | 说明 |
| --- | --- | --- |
| 图文位置 | `左文左列表 + 右图` / `右文右列表 + 左图` | 镜像靠 `.is-reversed`（只改 order，不改 DOM 顺序） |

- 勾选网格：2 列短条目，扫读最快（对应参考图 1、5）
- 图标列表：单列图标 + 标题 + 一句解释（对应参考图 3）
- 编号步骤：01–04 + 细分割线，天然带流程语义
- 数据行：左侧大数字 + 右侧说明（对应参考图 4）

## 四、结构 03 · 左文 + 左列表 + 右列表

左边文案配一个列表，右边再放「另一个维度的列表」。参考图：`结构3-多列表/`。

| 变体 | 类名 | 左列表 | 右列表 |
| --- | --- | --- | --- |
| A 右侧大图卡 | `.m3--a` | 4×2 图标网格（细线分隔） | 2 张「图 + 标题 + 说明」大卡 |
| B 三段式中图 | `.m3--b` | 圆形材质色板 | 中间竖图 + 右侧紧凑图标列表（三栏） |
| C 缩略图文行 | `.m3--c` | 横排标签（chips） | 3 条「小图 + 文字」图文行 |
| D 图片宫格 | `.m3--d` | 编号列表（带描述） | 2×2 图片宫格，图注压图 |

- **明暗主题**：切到「深色」会给区块加 `.is-dark`，只覆盖 CSS 变量（`--ink / --line / --paper / --accent`），所有子组件自动跟随。

## 六、结构 05 · 轮播列表（轮播图组件内嵌列表）

参考图：`结构5-轮播列表/`。轮播图本身是一个列表组件（若干轮播页），**每个轮播页 = 一张整幅背景图 + 标题文案 + 一组列表（列1）**，即「列表套列表」。背景只做简单的线性/径向渐变蒙层保证文字可读，不做花哨的毛玻璃卡；列表项**只保留 图标 + 标题**（重点在图标）。

| 控制项 | 取值 | 说明 |
| --- | --- | --- |
| 轮播页数 | `2 / 3 / 4` 页 | 每页 = 一张整幅背景图 + 标题文案 + 一组列表 |
| 列表样式 | 图标列表 / 编号列表 / 勾选列表 / 图文行 | `.m5--icon` `-num` `-check` `-row`；图标列表 = 图标方块格（参考图样式） |
| 文字位置 | 文字居左 / 文字居右 / 居中浮卡 | `.m5--left` `-right` `-bg`；均为整幅背景图，仅内容浮层位置不同 |
| 轮播控制 | 箭头+分页 / 仅箭头 / 仅分页 / 无 | 箭头圆形悬浮，分页点随页变宽 |
| 自动播放 | 开 / 关 | 开时每 4.2s 自动翻页 |

每页结构：

```html
<div class="m5 m5--icon m5--left count-3">
  <div class="m5__viewport">
    <div class="m5__track" style="transform:translateX(-0%)">
      <li class="m5__slide">
        <div class="m5__frame">
          <figure class="m5__media"><img src="…" alt=""><!-- 整幅背景图 --></figure>
          <div class="m5__body">
            <p class="m5__eyebrow">…</p>
            <h3 class="m5__title">…</h3>
            <p class="m5__lede">…</p>
            <ul class="m5__list"><!-- 列1：图标+标题 --></ul>
            <a class="btn m5__cta">…</a>
          </div>
        </div>
      </li>
      …
    </div>
  </div>
  <i class="m5__arrow m5__arrow--prev">…</i>
  <i class="m5__arrow m5__arrow--next">…</i>
  <div class="m5__dots">…</div>
</div>
```

## 七、装修编辑页（`editor.html`）

按你给的后台截图复刻的三栏编辑器：**顶部工具条 + 中间画布 + 右侧设置面板**。
`index.html` 顶栏右侧的「装修编辑页 ↗」进入，编辑器左上角第一个图标返回变体库。

### 7.1 面板结构（对照截图）

| 区域 | 内容 | 对应截图 |
| --- | --- | --- |
| 顶栏 | 图标组 / PC·Home·页面切换 / **模块下拉（切换 5 种结构）** / 头像 + 保存 | p1 |
| 面板头 | `列` + 重置 + 收起 | p2 |
| Tab | 设计 / 动画 / 预设 | p2 |
| 图文列表 | `1/2` 计数 + `新增`、缩略图横排（点选、悬停删除）；**多列表上方有「列 1 / 列 2」Tab**，分别管理左列表（8 项）与右列表（4 项）；**轮播列表：两个 Tab——「轮播列表」（轮播页缩略图）/「内部列表」（选中轮播页的内部列表项）**，两级都可`新增`/删除 | p2 |
| 视频 | `新增` → 添加视频占位 | p2 |
| 文本设置 | 标题 / 副标题 / 简介（每项都带眼睛开关） | p2 |
| 按钮设置 | 加号新增、图标位置（居左/无/居右）、按钮文字、配色方案、按钮链接 | p2 |
| 链接 | 模块整体跳转链接 | p2 |
| 更多内容设置 | 7 个图标：布局排版 / 背景设置 / 图片风格 / 视频设置 / 轮播设置 / SEO 设置 / 显示设置 | p3–p8 |

### 7.2 设置项 → 具体生效的东西

**布局排版**
- `列表布局`：结构4 = 网格 / 瀑布拼排 / 主次宫格；结构1 = A 双列均布 / B 错位偏移 / C 紧凑内联 / D 编号序号；结构2 = 勾选网格 / 图标列表 / 编号步骤 / 数据行；结构3 = A 大图卡 / B 三段式 / C 缩略图文行 / D 图片宫格；结构5 = 图标列表 / 编号列表 / 勾选列表 / 图文行
- 结构5 另有 **文字位置**（文字居左 / 文字居右 / 居中浮卡，均为整幅背景图），与 **列表间距**（列表项之间的间距）
- **结构4 三种布局都按「图文列表」的真实图片数（1–10 张）出不同排列**：瀑布内置 1–10 的成套错落模板（每套都有跨行大格 + 小格穿插、逐格铺满无洞，>10 张截取前 10），主次宫格同数量成套无洞模板，网格按列数自动排布、单张图通栏显示；在「图文列表」里新增/删除图片，画布排版即时重排
- `排布方向`（仅结构1）：竖向（左右各成列，上下顺读）/ 横向（列表项左右并排，阅读顺序左右交替）
- **结构1 的数量不是设置项**：直接由「列表项」里的内容数量决定，新增/删除列表项画布即更新；画布只渲染模块本身，不带头部文字与按钮
- `列数`：网格模式下 2 / 3 / 4 列（结构4）
- `容器对齐`：模块整体靠左 / 居中 / 靠右
- `文案对齐`：标题、简介、按钮的水平对齐
- `宽度`：模块占画布宽度 30%–100%
- `列中间距`：0 / 8 / 16 / 24px 或自定义
- `文案背景`：给标题块加半透明底色、圆角、内边距

**背景设置**：卡片背景（背景色 / 描边 / 相邻描边合并 / 圆角 / 内边距 / 投影 X·Y·模糊·扩散）与容器背景（同样六项）

**图片风格**：图片比例（无 / 1:1 / 4:3 / 16:9 / 3:4）、图片效果（原图 / 黑白 / 柔化 / 放大裁切）、图片背景与描边、圆角、图片对齐、内边距、**开启蒙层**（开启后在图片上叠一层黑色半透明遮罩，下方出现「蒙层透明度」滑杆 + 数值输入，0–1 默认 0.3；五种结构的图片都生效）

**视频设置**：视频比例、播放方式、循环 / 静音 / 自动播放、显示播放图标、显示控件、播放时隐藏文字和按钮、开启蒙层（画布用播放徽标 + 蒙层模拟）

**轮播设置**：是否轮播 / 循环 / 切换箭头 / 分页点 / 轮播间隔（网格模式下自动变成横向轮播轨道，到点翻页）；**结构5 本身就是轮播**，此面板改为「循环 / 箭头 / 分页 / 自动播放 / 间隔」，画布内箭头和分页点可直接点击翻页

**SEO 设置**：ALT 标签与标题属性（直接写进 `<img alt>` / `title`）

**显示设置**：标题 / 副标题 / 简介 / 按钮 四个显隐开关

**动画 Tab**：入场动画（无 / 淡入 / 上移 / 缩放）+ 时长 + 延迟 + 预览

**预设 Tab**：暗色海报 / 圆角卡片 / 明亮画册 / 居中文字——一键改写容器、卡片、图片、文案的样式参数

### 7.3 其它细节

- 视频 / 文本设置 / 按钮设置三个手风琴**默认收起**（列表项与更多内容设置默认展开），需要时点开；
- 多列表的「列 1 / 列 2」Tab 只作用于列表项 / 文本设置（列 1 = 左列表，列 2 = 右列表），「更多内容设置」对整列通用；
- **结构5（轮播列表）**：面板顶部提供 **两个 Tab——「轮播列表」和「内部列表」**（原“列 1”现已正式更名为“内部列表”）：
  - **概念定义**：「内部列表」即为当前所选轮播海报“图片”的内嵌列表。若在「轮播列表」选了图片 1，内部列表即为图片 1 的内部列表项（如 Free Delivery、Solid Oak...）；若选了图片 2，内部列表即为图片 2 的内部列表项。
  - **双层独立布局设计**：
    1. **轮播列表 Tab（主层）**：负责海报背景图缩略图、整页增删、整页标题/副标题/简介。其布局面板包含：**容器对齐**（9 宫格自由对齐）、**文案对齐**（左/中/右）、**宽度**（大标题/简介/列表组/按钮在海报中的整体宽度占比）、**文案背景**（圆角、背景色、描边样式/粗细/颜色、内边距，以及专属的**文案跟随版心**开关，默认开启）、**间距**（大标题、简介、内部列表整体、按钮之间的垂直外层间距）。
    2. **内部列表 Tab（内层）**：缩略图直观呈现各列表项的专属图标与图片1/图片2...标识。其布局面板包含：**列表布局**（1列 / 2列 / 3列 / 4列 下拉选择，默认 3 列）、**容器对齐**（控制 6 个列表组在父级中的水平靠左/居中/靠右，上中下对齐置灰禁用）、**图文对齐**（图标+文字整体居左/居中/居右对齐）、**宽度**（仅作用于内部列表组本身，不干扰大标题、简介与按钮）、**文案背景**（卡片圆角、背景色、描边样式/粗细/颜色、内边距，无跟随版心开关）、**列表间距**（卡片相互之间的行列网格 gap）。
    3. **按钮样式规范**：轮播内的操作按钮（Read More）默认使用透明/白底底色搭配纯黑文字与黑细描边（`border: 1.5px solid #111418; color: #111418`），轻盈干净。
    4. **背景与描边设计器规范（全局统一）**：所有结构（m1 ~ m5）下的卡片背景、容器背景、文案背景均已升级为统一的一比一设计器规范：
       - **图 1「容器对齐」**：双 Tab 组水平铺满并排（水平左/中/右 + 垂直上/中/下），支持卡片圆角高亮与轻投影，内部列表专属垂直对齐置灰禁用；
       - **图 2「列表布局」**：采用白底、浅灰细边框（`#d0d5dd`）、圆角 8px 与定制轻细下箭头 SVG，彻底清除系统原生粗黑三角与双重箭头；
       - **图 3「文案背景」**：圆角与内边距采用单位标签上移（`px ˅`）+ 统一/独立双图标切换按钮（32px 高度与右侧输入框严格水平对齐），独立模式下展开 4 个方向分立浅灰输入框；背景与描边支持圆形勾选、胶囊药丸色块卡片、调色盘、实线/虚线/点线下拉与三横线线宽输入框；轮播主层保留文案跟随版心开关；
       - **UX 体验重构（轮播列表先行试点）**：针对拥挤与纵向未对齐痛点，圆角与内边距的标题**各自独占一行**（`圆角 px ˅`、`内边距 px ˅`）；统一与独立的开关采用 **74px 宽的双 Tab 分段选择器**；左侧列统一为 74px 固定标签/Tab 列（圆角双 Tab、勾选背景、勾选描边、线型下拉、内边距双 Tab），右侧为统一输入区：**圆角输入框、背景颜色卡片、描边颜色卡片、描边宽度输入框、内边距输入框的左边缘严格对齐在同一竖直基准线上（精确至像素级 0 误差对齐）**，界面舒朗规整、层次分明。
  - **画布与选择联动**：点击轮播页选中该页，点击页内列表项选中该项并高亮。改动即时生效并持久化至 `localStorage`。
- 画布**点卡片**即可选中，面板 `图文列表` 的 `1/2` 和缩略图同步高亮；
- 文本 / 数字 / 颜色 / 滑杆改动只重绘画布，不会让输入框失焦；开关、分段、下拉会即时重绘整个面板；
- **面板滚动位置会保留**：改设置、点预设、折叠区块、切分栏图标都不会跳回顶部；切换 Tab 会记住各 Tab 上次滚到的位置；只有「换结构」和「重置模块」才回到顶部；
- 所有改动自动存 `localStorage`（键 `module-editor-v1`），刷新还在；`保存` 按钮给一次确认提示，面板头部的圆形箭头 = `重置当前模块`；
- 结构1–3 的列表项文案可在「文本设置 → 第 N 项内容」里逐条编辑；
- 浅色容器上的描边/白色按钮会自动换成深色，避免看不见；
- ≤860px 时右侧面板变成抽屉，由右下角「设置」按钮唤出。

### 7.4 模块化架构与命名空间（重构后规范）

编辑页代码已按关注点与职责进行正交拆分，杜绝全局污染与样式层叠覆盖：

1. **样式分层**：
   - `editor-shell.css`：编辑后台顶栏、侧边设置面板、手风琴、表单控件样式；
   - `editor-canvas.css`：画布覆盖专用样式（全部带 `.ed-mod ` 前缀），**永远作为最后一个 `<link>` 引入**，确保画布排版不受后台 UI 干扰。
2. **脚本模块化（挂载至 `window.ED`）**：
   - `editor-defs.js`：模块元数据 `STRUCTURES`、`MODES`、默认模型 `defaults()` 与 `PRESETS`；
   - `editor-fields.js`：布局判定 `isVert`/`isHoriz`，通用控件片段 `seg`、`sw`、`range`、`dimCtl` 等；
   - `editor-panels.js`：布局、背景、图片风格等通用属性设置面板；
   - `editor-m1.js`：双排列表专属面板（主图对比滑块、地图、比例设置）；
   - `editor-m5.js`：轮播列表专属面板（轮播页与页内列表二级 Tab 联动）；
   - `editor-canvas.js`：根据 `state` 渲染五类结构的画布 DOM（依赖提前加载）；
   - `editor-core.js`：状态管理（`ED.state` / `ED.ui`）、持久化、双向事件绑定与主入口。

## 八、交互与响应式细节

- 桌面端（>1080px）控制条**吸顶**，滚到变体内容时仍可随手切换；窄屏改回普通流式排列。
- 结构1 在 ≤1080px 时把左右两列列表**合并成同一个两列网格**（靠 `display:contents`），避免「左 3 项 / 右 3 项」各自换行产生空洞；≤640px 收成单列。
- 结构2/3 在 ≤1080px 改为上下堆叠，图片始终在上；结构3 的三栏在 ≤1080px 降为两栏 + 通栏列表。
- 结构4 在 ≤900px 重排为两栏宫格，图注常显（触屏没有 hover）。
- 结构5 在 ≤900px 内容浮层改为贴底通栏（背景图蒙层改为自下而上的渐变，保证文字可读）；≤640px 列表由三列收成两列。

## 九、怎么用

1. 选一个结构 + 一个变体（控制条点出来最满意的那个）。
2. 到 `assets/js/modN.js` 的 `render()` 里复制生成的 HTML，或直接照类名手写。
3. 把变体类名写到根元素上，删掉控制条（`.ctrl`）和 `main.js`：

```html
<!-- 例：结构1 的 B 变体、4 项、竖向 -->
<div class="m1 m1--b count-4 is-v"> … </div>

<!-- 例：结构2 的镜像 + 图标列表 + 55% 图 -->
<div class="m2 m2--list-icon is-r55 is-reversed"> … </div>

<!-- 例：结构4 的 Bento + 26px 间距 + 20px 圆角 -->
<div class="m4 m4--d is-gap-l is-r20 has-caps"> … </div>

<!-- 例：结构5 的 图标列表 + 文字居右 + 3 页 + 箭头+分页 -->
<div class="m5 m5--icon m5--right count-3">
  <div class="m5__viewport"><div class="m5__track">…</div></div>
  <i class="m5__arrow m5__arrow--prev">…</i>
  <i class="m5__arrow m5__arrow--next">…</i>
  <div class="m5__dots">…</div>
</div>
```

### 设计变量（`base.css` 顶部）

| 变量 | 作用 |
| --- | --- |
| `--ink / --ink-soft / --body / --muted` | 文本层级 |
| `--line / --line-strong` | 分割线与描边 |
| `--paper / --sand / --sand-deep` | 背景层级 |
| `--accent` | 强调色（序号、图标、eyebrow） |
| `--max / --pad` | 内容最大宽度 / 左右安全边距 |
| `--r-sm / --r-md / --r-lg` | 圆角 |
| `--shadow-s / --shadow-m` | 阴影 |

### 断点

| 断点 | 行为 |
| --- | --- |
| `> 1080px` | 桌面多栏布局 |
| `≤ 1080px` | 结构1/2 上下堆叠（图在上）、结构3 三栏降为两栏 |
| `≤ 900px` | 结构4 宫格重排为两栏、结构5 图文左右改上下两段 |
| `≤ 760px` | 列表降为单列、宫格图注常显、结构5 双列列表收单列 |

## 十、备注

- 图片全部来自 Unsplash，仅作排版占位；换图只需改 `assets/js/data.js` 里的地址。
- 文案为虚构品牌 HAVEN 的演示内容，长度按「真实英文长句」设定，方便判断换行与舒适宽度。
- 全局背景与描边设计器规范（2026年升级）：全组件统一升级「文案背景」、「卡片背景」与「容器背景」排版规范。圆角与内边距标题独立成行（带 `px ▾` 单位下拉标签），统一/独立切换升级为 74px 宽分段药丸底座；左侧控制区统一保持 74px 宽，右侧所有输入框（圆角数值框、背景/描边颜色药丸卡片、描边粗细输入框、内边距输入框）严格纵向左对齐在同一垂直基准线上（0px 偏差），彻底消除视觉拥挤感。
- 结构5（轮播列表）单页独立排版特性：在「更多内容设置」首个 Tab【布局排版】顶部增加「独立设置」Switch 开关及带 hover 浮层提示的 `i` 图标。开启后，当前选中的轮播项深拷贝继承全局配置作为初始值，后续对其容器对齐、文案对齐、宽度、文字背景设置、内部列表布局、间距等修改仅对当前轮播页生效，画布实时按单页独立渲染，缩略图带有「独立·图片N」专属状态标记；关闭则自动无缝切回全局统一排版。
- 全局排版规范与控件顺序统一（2026年升级）：
  1. 内部列表与复合列表统一支持「列数设置」下拉选择器样式；
  2. 双排列表「排布方向」统一升级为「列数设置」下拉选择器（默认2列，选4列时横向排列）；
  3. 全局统一将所有列表间距命名为「列中间距」；
  4. 统一「更多内容设置」首个 Tab【布局排版】字段展示顺序：列表布局 ➔ 图文布局 ➔ 列数设置 ➔ 容器对齐 ➔ 图文对齐 ➔ 文案对齐 ➔ 上下对齐 ➔ 宽度 ➔ 列中间距 ➔ 图文比例 ➔ 文字背景设置；
  5. 第三个 Tab【图片风格】背景描边全量升级为最新设计器规范（圆角/内边距独立标题带下拉，74px统一/独立双Tab，右侧输入框严格左对齐）。
- `tools/` 是做视觉自检用的 headless Chrome 截图脚本，不影响页面运行，可以直接删：
  - `node tools/shot.mjs tools/shots.json .shots` —— 1440 宽逐变体截图
  - `node tools/shot.mjs tools/shots-mobile.json .shots-m` —— 760 / 390 宽截图
  - 编辑页截图：配置对象里写 `"page": "editor.html"`，`eval` 里可以直接点面板控件（如 `document.querySelector('[data-act="seg"][data-bind="layout.columns"][data-value="3"]').click()`）；
  - 脚本会顺带报告页面 JS 报错，并在启动前清掉残留的无头 Chrome。
