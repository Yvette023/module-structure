# Banner 智能体 · HTML 交互原型

围绕「运营后台配置 → 提示词模版绑定 → 装修端小鱼AI 调用」的一条完整链路，
把 **图文布局**、**生成文案**、**模版联动** 三件事做成可点击、可验证的页面。

打开 `index.html` 即可。纯静态、无构建、无依赖；图片为项目内参考图裁切，本地加载。

## 页面

| 文件 | 对应场景 | 内容 |
| --- | --- | --- |
| `index.html` | 总览 / 复制智能体 | 5 种布局实时预览、完整链路、4 个场景入口、复制「banner生成」智能体演示 |
| `admin.html?view=workflow` | **P1 运营后台 · 工作流** | id:2 的「生成文案」下拉与文案标准提示词；id:6/8 提示词与图文布局下拉（两路一致） |

| `editor-ai.html` | **P3 装修 · 小鱼AI 生成配置** | 店铺画布 + 小鱼AI 面板；默认不展示生成配置，点「banner生成」右侧按钮弹出悬浮配置面板；读取后台已发布配置并真实出图；画布内置 3 张默认轮播，应用内容追加新页 |

- `editor-ai.html?tpl=tpl-2&modal=templates`：载入模版并打开模版库
- `editor-ai.html?from=admin`：模拟从运营后台进入

## 关键交互

**P1**

- 角色定义 → 输出设置 → 生成文案：下拉选择「生成文案（图片 + 文案）」或「不生成文案（仅图片）」
- 图像生成 id:8、id:6 → 输出设置 → 图文布局（位于「尺寸」下方）：左图右文（默认）/ 右图左文 / 上图下文 / 下图上文 / 文字居中，均为下拉
- id:6 与 id:8 输出设置完全一致（模型、数量、比例、布局、分辨率、填充到），改任一路两路同步
- 顶栏「保存草稿」写入草稿、「发布」才让小鱼AI 生效；状态显示 `vN · 已发布 / 有未发布改动`
- 节点内提示词（角色定义 / 提示词增强 / 图像生成）可直接编辑，随发布同步到小鱼AI
- **选择对象**：两级级联选择器 —— 一级为页面组件（幻灯片-1 / 企业优势 / 多行图文…），带下级箭头的项（如轮播图）点进去是二级元素（图片1 / 标题1 / 描述1 / 按钮1…）；支持搜索、返回上级、点外部或 Esc 关闭
- 顶部「本次变更 3」可一键定位到新增项并放大查看

**P2**

- 模版编辑弹窗：名称、描述、封面、参考素材、**图文布局**、权重、分类、提示词
- 图文布局放在「参考素材」下方，选中后展示结构说明
- 保存后，模版详情、列表角标、调用说明同步更新
- 详情页可直接跳转装修端查看联动效果

**P3 / P4**

- 默认不展示生成配置，点「图文生成」右侧的滑杆按钮弹出悬浮面板（无遮罩、不打断画布）
- 面板内：文本模型 / 图片模型 / 比例 / 生成数量 / **图文布局** / **生成文案**（并排）+ **分辨率**（整行）+ **尺寸**（整行）
- 图文布局、生成文案为下拉框，改完即时生效；面板无底部按钮，点外部或按钮收起
- 面板值来自后台已发布版本；临时改动只在本次页面有效，刷新回到已发布配置
- 右上角「接口」可填 OpenAI 兼容生图接口，配好后真实调用远端出图
- 提示词模版改为图库：全部 / Banner / 产品图 / 封面图，16:9 缩略图，悬停出现「做同款」，点击即套用
- 选中模版后，输入框上方出现方形缩略图，随消息一起发出；发送后 AI 回复为无头像的图文卡片（标题/副标题/标签/简介 + 大图 + 应用到 · 选择对象）
- 发送后用户气泡右对齐；底部入口为「banner生成」+ 生成配置按钮

## 工作流节点提示词（已按高端广告摄影调优）

| 节点 | 职责 | 关键约束 |
| --- | --- | --- |
| **id:2 角色定义** | 文案质量 | 标题 ≤12 字、副标题 ≤20 字、标签 3 个、简介 ≤45 字；**禁用「震撼/超值/必买/爆款/疯抢」等廉价词**；语言跟随用户输入 |
| **id:5 提示词增强** | 画面质感规范 | 大画幅广告摄影影调：单一柔和主光 + 轮廓光、高光受控、暗部有细节、材质纹理清晰；低饱和高级灰、色温统一；轻微暗角收束视线。作为**静态约束追加，不额外调用模型，零延迟** |
| **id:6 / id:8 图像生成** | 构图与合规 | 中景偏近，产品占画面 45%–55% 且为唯一视觉焦点；前景虚化 / 主体 / 背景纵深三层；严禁纯色块、分栏、边框、拼接、任何文字 |

### 速度实测（Qwen Image 3.0，16:9 1K）

| 变量 | 耗时 |
| --- | --- |
| `prompt_extend: false` | **3.5–4.6s** |
| `prompt_extend: true` | 39.4s（**慢 9 倍，默认必须关闭**） |
| 2K（2048×1152） | 9.9s（约 1K 的 2.4 倍） |
| 负面词 | 几乎无影响 |

端到端（文案模型 + 图像模型 + 合成）实测 **6–9s，平均 7s**，6 个模版全部成功。

## 运营后台 ↔ 小鱼AI 的打通方式

这是**真实打通**，不是两张互相独立的静态页：

```
运营后台改配置 → 保存草稿 → 点「发布」（版本号 +1）
                                    ↓  localStorage + storage 事件
小鱼AI 读取「已发布版本」 → 生成 → Canvas 真实出图（PNG 可下载）
```

- `assets/js/store.js`：共享配置中心。分为 `draft`（草稿）和 `published`（线上）两份。
  后台编辑只动 `draft`；点「发布」才把草稿覆盖到 `published` 并递增版本号。
- 小鱼AI 只读 `published`，所以**后台改了没发布，前台不会变**；已打开的小鱼AI
  页面收到 storage 事件会自动同步并提示「已发布 vN」。
- 同步内容：生成文案开关、图文布局、文本/图像模型、数量、比例、分辨率、填充到、
  角色定义提示词、提示词增强、图像生成提示词、提示词模版列表。
- 台前临时改动（改布局、换数量、选模版）只影响当次页面，刷新即回到已发布配置。

## 生成是怎么落地的

- `assets/js/render.js`：Canvas 渲染引擎。按 `layout / copy / theme / photo / ratio / resolution`
  真实绘制图片与文案，输出 PNG（点「查看大图」可下载）。
- 文案由「用户输入关键词 + 工作流角色提示词 + 模版文案结构」合成，不再写死；
  选「不生成文案」时只出图，文案位留空。
- 参考图（输入框左侧「+」）决定走哪一路：无参考图 → **id:8 文生图**，有参考图 → **id:6 图生图**。
- 每条结果可展开「查看生效配置」，能看到执行节点、布局、文案开关、模型与工作流版本。

## 真实生图接口（已接入 Qwen Image 3.0）

已实测接入 **ModelVerse / Qwen Image 3.0**，生成是真实调用：

```
POST https://api.modelverse.cn/v1/images/generations
Authorization: Bearer <key>
{ model, prompt, size:"W*H", n, prompt_extend, watermark, negative_prompt, image? }
```

实测结果：1024² 约 4.6s、1280×720 约 5.4s、2048×1152 约 15.8s、图生图（base64 参考图）约 6.6s；
接口与 OSS 均返回 `Access-Control-Allow-Origin: *`，浏览器可直连。

两种出图方式（生成配置面板右上角「接口」可切换）：

| 方式 | 说明 |
| --- | --- |
| **AI 底图 + 本地排版**（默认） | 调 Qwen 出**无字底图**，再用工作流布局把文案精确排进去，文字最可控 |
| **AI 整图生成** | 文案也交给模型画，风格更自由，文字准确度依赖模型 |

- 请求 prompt 由【用户输入】+【风格提示词】+【参考图】+【画面要求】+【构图】拼装
- **景别与占比**：产品不能顶满画面。写法是「中远景，产品约占画面 30%–40%，四周由同一场景自然延伸」，
  ⚠️ 不能写"留白 / 留出空间给文字"——模型会画成纯色块（见下条）
- **上传产品图 + 选模版**：上传图是**唯一主体**（外形/结构/颜色/材质原样保留），
  模版风格提示词降级为【环境参考】（只借环境、光线、氛围），模版原有产品写入【排除】并加入 negative_prompt。
  原因：模版参考图本身并不发给模型，混图是风格提示词**文字**里描述的产品被模型画了出来
- **所有生图（无论是否生成文案、是否选模版）统一走纯摄影提示词**：
  一旦提示词里出现 banner / 底图 / 主视觉 / 海报 / 文案 / 标题 / 文字 / 标签 / 图标，
  模型就会自作主张画出版式、大标题和乱码字。文案由前端叠加，模型完全不需要知道"这是 banner"。
  因此提示词一律写成「一张专业的产品商业摄影原片」，negative_prompt 统一精简（过长反而干扰画面）。
  模版「提示词」是**可复用空位**：用 `【{产品}】` 占位（如「在暖棕影棚的错落展台上，陈列【{产品}】」），
  选模版后自动填入并选中占位符，用户直接打字即可替换；未替换时发送会被拦截。
  风格提示词只写环境 / 光线 / 陈列方式，不写主体的位置与数量
- **生图提示词里绝不能出现「主体在左/右」「留出空间/留白」这类排版要求**：
  模型会理解成左右分栏 + 一块纯色，导致画面割裂。图文布局只用于后端文字叠加，不进入生图提示词
- **参考图分两种语义**（关键）：
  - 用户自己点「+」上传的图 → 真发图生图，主体沿用参考图
  - 模版的参考图 → 默认 `refMode: 'style'`，**只提取风格写进提示词，不发给模型**，
    并把模版原有主体写进 `negative_prompt`，避免「提示键盘却画出摄像头」
- `negative_prompt` 强约束「不要出现文字 / 字母 / 水印 / logo / 按钮」
- 出图只交付**纯净画面**：不叠加标题、按钮，底图铺满整幅
- `prompt_extend` 默认关闭（开启会走二次改写，耗时约 40s），可在接口面板打开
- 接口失败自动回退本地合成，并在「查看生效配置 → 出图方式」标明原因

## 文案由真实文本模型生成（id:2 驱动）

标题 / 副标题 / 标签 / 简介不再写死，改为调用文本模型：

```
POST https://api.modelverse.cn/v1/chat/completions
model: gpt-4o-mini / gpt-4.1-mini
system: 工作流 id:2 的角色定义提示词（约束字数、语调、语言）
user:   【用户输入】+【风格提示词】+【参考图】+【图文布局】
response_format: json_object
```

- id:2 提示词定义了输出标准：标题 ≤14 字、副标题 ≤24 字、标签 3 个、简介 ≤50 字
- 语言跟随用户输入（中文出中文、英文出英文），风格贴合模版的风格提示词
- 模型失败时回退本地规则生成，并在「查看生效配置 → 文案模型」标注「失败，已本地兜底」

> Key 内置在 `assets/js/data.js` 的 `apiDefault`，也支持在接口面板改成你们自己的网关。
> 这是前端直连、Key 会暴露在页面里，**仅适用于原型演示**；上线请换成服务端代理。

## 数据与结构

- `assets/js/data.js`：5 个布局、6 个参考图模版（含 `refs` 参考素材数组）、图片、模型目录（Qwen Image 3.0 ×2 / GPT ×2）、内置接口配置
- `assets/js/img-data.js`：内嵌 data URL 图片（Canvas 合成与图生图入参）
- `assets/js/img-data.js`：内嵌 data URL 图片（避免 file:// 下 Canvas 被判跨源）
- `assets/js/store.js`：草稿 / 发布 / 版本 / 模版 / 接口配置
- `assets/js/render.js`：Canvas 出图引擎
- `assets/js/ui.js`：图标、Toast、弹窗、布局缩略图、预览渲染
- `assets/js/hub.js` / `admin.js` / `editor.js`：各页面交互
- `assets/css/base.css`：设计变量与通用组件；`hub/admin/editor.css`：页面样式
